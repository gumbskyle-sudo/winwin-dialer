HOW THE RECORDINGS WORK
═══════════════════════════════════════════════════════════════════

  Upload:
    • On any dialer card, tap "📋 VA / pre-existing notes" to expand
    • Tap "🎙 Upload recording" — pick an audio file from device
    • 25 MB cap, common formats supported (mp3, m4a, wav, ogg, webm)

  Playback:
    • Tap the recording's filename
    • Opens in the device's default media player
      (iOS: QuickTime/Files · Android: default audio app · Desktop: browser audio)

  Storage:
    • Files live in private Supabase Storage
    • Signed URLs expire 1hr after page load — refresh card to renew
    • Auto-deletes after 30 days
    • Manual delete via the ✕ button next to each recording

  Cleanup:
    • Runs automatically once every 24 hours when anyone opens the app
    • Tracked in localStorage so it doesn't spam the server
